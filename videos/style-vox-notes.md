## 화면
- **세계관 하나로 끝까지:** 8비트 픽셀 게임. 고장 난 자동차가 갈림길 미로 앞에 서 있고, 선택지 6개가 미로의 길이다. 처음부터 끝까지 같은 세계 안에서 움직인다.
- **색:** 종이 질감의 미색 배경 + 짙은 회색, 강조색 2개(초록 = 괜찮은 쪽, 코랄 핑크 = 비용·위험), 동전·가격표는 노랑.
- **숫자 보여주기:** 큰 숫자 하나씩. 시간은 '도로'처럼 가로로 흐르고(1월→12월), 이자는 지폐 더미가 쌓이는 그림.
- **장면 전환:** 약 2.5~4초마다 화면이 바뀐다. 한 장면 안에서도 아이콘·글자가 1.5~2초마다 조금씩 움직인다.
- **출처:** 숫자마다 화면 아래쪽에 출처를 작게 붙인다. 설명란에 출처 링크를 모은다.

## 말
- 거의 전부 목소리만(보이스오버). 얼굴은 광고 구간에만.
- 문장이 짧고 차분하다. 겁주거나 훈계하지 않는다.
- 신호 문장: "먼저 접근성부터 보죠", "이건 나중에 다시 볼게요", "여기서부터 복잡해집니다".
- 큰 숫자를 말하기 직전에 아주 짧게 멈춘다.

## 소리
- 칩튠(8비트) 느낌의 잔잔한 전자음악. 위험한 선택지에서 긴장감이 살짝 올라간다.
- 동전 소리, 메뉴 선택음, 경고 버저 같은 게임 효과음.

## 우리 채널이 가져올 기법
1. **2인칭 상황으로 시작:** "에어프라이어를 하나 사려고 한다고 해 봅시다."
2. **숫자 하나 + 화면 출처:** 첫 30초에 숫자는 하나만, 출처를 붙여서.
3. **범위 좁히기 문장:** "이유는 많지만, 오늘은 딱 하나만 봅니다."
4. **같은 대상을 두 기준으로 두 번 돌기:** 예) A·B·뽀큐트를 1회차 '얼마나 많이 보나', 2회차 '얼마나 판단을 맡기나'.
5. **세계관 하나:** 우리 시리즈의 '인벤토리'(게임) 세계관이 Vox의 픽셀 게임과 잘 맞는다.
6. **고정 점수판:** 화면 구석에 계속 떠 있는 상자(예: "계산대 위치: 채널 밖 → 안").
7. **끝에서 한 발 물러서기:** 채널 하나의 이야기에서 "판매 전반"의 이야기로 넓히고 클로징.
